# ✅ **THE CORE PROBLEM**

Your `fetchAllData()` is calling several functions that each use `throw new Error(...)`.
The moment *any* of them fails → **the whole thing crashes** → `"Failed to load data"`.

But more importantly:

### **You are using `Promise.all` inside each fetch function.**

So one failed request breaks that entire section.

### **And!**

Your `processItem()` inside `resource-fetcher.ts` is extremely strict. If any property is missing or undefined → it throws.

This means **your frontend will break the moment any of your API routes returns something unexpected**, including:

* empty array
* missing field
* changed field names
* network timeouts
* offline backend

So the crash is normal.

import axios from "axios";
import type {
  ExpenseResponse,
  BalanceResponse,
  GoalResponse,
  SubscriptionResponse
} from "@/types/api";

const API_BASE_URL = process.env.NEXT_PUBLIC_API_URL || "http://localhost:3001";

const safeRequest = async <T>(promise: Promise<T>, fallback: T): Promise<T> => {
  try {
    return await promise;
  } catch (err) {
    console.error("API route failed:", err);
    return fallback;
  }
};

export const fetchExpenses = async (): Promise<ExpenseResponse[]> => {
  return safeRequest(
    axios.get(`${API_BASE_URL}/expenses`).then((r) => r.data),
    []
  );
};

export const fetchSubscriptions = async (): Promise<SubscriptionResponse[]> => {
  return safeRequest(
    axios.get(`${API_BASE_URL}/subscriptions`).then((r) => r.data),
    []
  );
};

export const fetchGoals = async (): Promise<GoalResponse[]> => {
  return safeRequest(
    axios.get(`${API_BASE_URL}/goals`).then((r) => r.data),
    []
  );
};

export const fetchBalance = async (): Promise<BalanceResponse[]> => {
  return safeRequest(
    axios.get(`${API_BASE_URL}/balance`).then((r) => r.data),
    []
  );
};

// MAIN
export const fetchAllData = async () => {
  const [expenses, subscriptions, goals, balance] = await Promise.all([
    fetchExpenses(),
    fetchSubscriptions(),
    fetchGoals(),
    fetchBalance(),
  ]);

  return {
    expenses,
    subscriptions,
    goals,
    balance,
  };
};
