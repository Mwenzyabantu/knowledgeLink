---
name: Instruction content formatting
description: The user's formatting requirement for KnowledgeLink's How to Build content.
---

Render sequential build guidance as separate numbered steps or bullets, and keep explanatory text in readable paragraphs where it needs more context. Do not leave multiple steps run together as one paragraph.

**Why:** The user asked for points and passages where appropriate instead of one continuous passage.

**How to apply:** When changing the How to Build instructions UI or generated instruction format, preserve semantic lists for steps and paragraphs for supporting explanations.
